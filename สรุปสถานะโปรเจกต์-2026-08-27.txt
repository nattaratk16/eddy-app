1) งานหลักที่ค้าง — เฟส 5: Deploy ขึ้น Vercel  [ยังไม่ทำ]
================================================================
งานหลักที่เหลือของโปรเจกต์ มี 4 จุดที่ต้องแก้ก่อน ไม่งั้น deploy จะพัง:

  (1.1) build script ไม่มี prisma generate                    [ต้องแก้]
        ไฟล์ : package.json (บรรทัด "build")
        ปัจจุบัน : "build": "next build"
        ปัญหา   : Vercel cache โฟลเดอร์ node_modules ไว้ พอ deploy รอบถัดไป
                  Prisma Client จะไม่ถูก generate ใหม่ตาม schema ที่แก้
                  -> build พังหรือ type ไม่ตรง
        ควรเป็น : "build": "prisma generate && next build"

  (1.2) ยังไม่มี AUTH_URL / AUTH_TRUST_HOST                    [ต้องเพิ่ม]
        NextAuth v5 (beta) ต้องรู้ URL จริงของโดเมน production
        ไม่งั้น callback ของ Google OAuth จะเด้งกลับผิดที่

  (1.3) Google OAuth redirect URI ตั้งไว้แค่ localhost           [ต้องเพิ่ม]
        อ้างอิง : .env.example ระบุ
                  http://localhost:3000/api/auth/callback/google
        ต้องเข้า Google Cloud Console เพิ่ม URI ของโดเมน production
        เช่น https://<ชื่อแอป>.vercel.app/api/auth/callback/google

  (1.4) ต้องตั้ง Environment Variables บน Vercel ให้ครบ 5 ตัว
        DATABASE_URL, AUTH_SECRET, GEMINI_API_KEY,
        AUTH_GOOGLE_ID, AUTH_GOOGLE_SECRET
        (+ AUTH_URL ตามข้อ 1.2)
