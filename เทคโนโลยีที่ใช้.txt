========================================================================
 ฝั่ง AI / การตัดสินใจ
========================================================================

  ใช้ AI (Gemini)  ->  โมเดล : gemini-flash-lite-latest  (Google)
    - แชท Eddy
    - แปลงข้อความ -> กิจกรรม/สิ่งที่ต้องทำ
    - วิเคราะห์ตารางตอนสร้าง event
    - สรุปภาพรวมสัปดาห์
    - แตกงานใหญ่เป็น subtask
    - เลือกว่าใครทำงานไหน (กระจายงานกลุ่ม)
    * โมเดล Gemini ตัวเดียวนี้ใช้กับทุกฟีเจอร์ AI ในแอป

  คำนวณเอง (local, ไม่ใช้ AI)
    - หาเวลาว่าง + วางเวลาไม่ให้ชน   ->  lib/freeTime.ts
    - Priority Score (เรียงงานควรทำก่อน)  ->  lib/priorityScore.ts
    - Fallback เมื่อ Gemini ล่ม/ไม่มี key  ->  lib/aiMock.ts

  หลักการ: งาน "ภาษา/ตัดสินใจ" = Gemini
           งาน "เวลา/ตัวเลขที่ต้องเป๊ะ" = โค้ดคำนวณเอง


========================================================================
 Stack หลัก
========================================================================

  Framework   : Next.js 14.2.5 (App Router) + React 18.3.1 + TypeScript
  Database    : PostgreSQL บน Neon (cloud) ผ่าน Prisma 5.17
  Auth        : NextAuth v5 (Auth.js)
                - Email/Password (เข้ารหัสด้วย bcrypt)
                - Google OAuth
  Styling     : Tailwind CSS (ธีม Genie custom)
                + ฟอนต์ IBM Plex Sans Thai


========================================================================
 ไลบรารีเด่น
========================================================================

  framer-motion 11   : อนิเมชัน (เมนูเลื่อน, การ์ดเด้ง, modal)
  @dnd-kit           : ลากสลับ subtask
  date-fns           : จัดการวันที่/ปฏิทิน
  lucide-react       : ไอคอน


========================================================================
 บริการภายนอก (External services)
========================================================================

  Neon              : cloud Postgres (ฐานข้อมูลจริง)
  Google Gemini API : ฟีเจอร์ AI ทั้งหมด
  Google OAuth      : ล็อกอินด้วยบัญชี Google
  Deploy            : ยังไม่ได้ขึ้น (รันในเครื่อง localhost)
                      -> เฟส 5 คือ deploy ขึ้น Vercel


========================================================================
 สรุปสั้น
========================================================================

  Next.js + Prisma/Neon + NextAuth(+Google) + Tailwind
  ฝั่ง AI ใช้ Gemini Flash Lite สำหรับงานภาษา/ตัดสินใจ
  และโค้ดคำนวณเองสำหรับงานเวลา/ตัวเลขที่ต้องแม่นยำ
