3) ระบบ Loop (ทำประจำ) - พัฒนาต่อ
================================================================
  - กันลงเวลาทับซ้อน: ตรวจทั้งตอนสร้างและแก้ไข
    เงื่อนไข = มีวันในสัปดาห์ซ้ำ + เวลาคาบเกี่ยว + ยังไม่หมดอายุทั้งคู่
    ชนแล้วบอกว่าไปชนกับอันไหน วันไหน เวลาเท่าไร
    (Loop ที่เลยวันใช้ถึงแล้วไม่นับว่าชน จะได้ลงวิชาเทอมใหม่ทับช่องเดิมได้)
    เทสต์ 5 เคส: ทับ/คนละวัน/ต่อกันพอดี/คร่อม/หมดอายุ ผ่านหมด
  - รหัสวิชา (courseCode): ใส่ได้ แสดงเป็นป้ายในรายการ
    และนำหน้าชื่อบนปฏิทิน เช่น "01076021 วิชา Database"
  - แก้ไข Loop ได้แล้ว (เดิมมีแต่เพิ่มกับลบ)
  - เอาข้อมูล Loop ไปใช้เพิ่ม 2 จุด:
    · analyze-event กางคาบเรียนของวันนั้นมาเทียบด้วย
      (เดิมเพิ่มกิจกรรมทับคาบเรียนแล้วระบบบอกว่า "ไม่ชน")
    · สรุปสัปดาห์นับ Loop เข้าไปด้วย (เดิมบอกว่าว่างเกินจริง)

================================================================
  - modal รหัสกลุ่มยิง API วนไม่รู้จบเมื่อเซิร์ฟเวอร์ตอบ error

  - การ์ด "เพิ่มในสิ่งที่ต้องทำ" กดซ้ำได้หลังรีเฟรช -> จำสถานะ added ไว้ใน draft
