########################################################################
#   EDDY — เอกสาร API ทั้งหมดของโปรเจกต์
#   (API ภายใน 29 endpoint + External API 4 ตัว)
########################################################################


========================================================================
 1) EXTERNAL API — บริการภายนอกที่ระบบเรียกใช้ (4 ตัว)
========================================================================

  Google Gemini API      : ฟีเจอร์ AI ทั้งหมด (แชท/วิเคราะห์/สรุป/แตกงาน/
                           กระจายงาน) — เรียกจาก lib/gemini.ts
                           โมเดล: gemini-flash-lite-latest

  Google OAuth 2.0       : ล็อกอินด้วยบัญชี Google — ผ่าน NextAuth

  Google Calendar API    : ดึงกิจกรรมจากปฏิทิน Google (อ่านอย่างเดียว)
                           เรียกจาก /api/google/calendar

  Neon (PostgreSQL)      : ฐานข้อมูล cloud — เข้าถึงผ่าน Prisma ในทุก route


========================================================================
 2) API ภายใน (Next.js API Routes — 29 endpoint)
========================================================================

  รูปแบบการทำงานของทุก route:
     ตรวจสอบสิทธิ์ (session) -> คุยกับ DB ผ่าน Prisma -> ส่ง JSON กลับ
     * route ของกลุ่มมีการเช็คสมาชิก/บทบาทเพิ่ม
     * ไม่มี backend แยก — เป็น API ในตัว Next.js ทั้งหมด


  ------------------------------------------------------------------
  [ AUTH — ระบบสมาชิก ]  (2)
  ------------------------------------------------------------------
  (auto)          /api/auth/[...nextauth]
                     NextAuth จัดการ login / logout / session /
                     callback / csrf ให้อัตโนมัติ
  POST            /api/auth/register
                     สมัครสมาชิก (email/password + เข้ารหัส bcrypt)


  ------------------------------------------------------------------
  [ CATEGORIES — หมวดหมู่ปฏิทิน ]  (2)
  ------------------------------------------------------------------
  GET, POST       /api/categories
                     ดึงรายการหมวดหมู่ / สร้างหมวดหมู่ใหม่
  PATCH, DELETE   /api/categories/[id]
                     แก้ไข / ลบหมวดหมู่


  ------------------------------------------------------------------
  [ EVENTS — กิจกรรมในปฏิทิน ]  (2)
  ------------------------------------------------------------------
  GET, POST       /api/events
                     ดึงกิจกรรมทั้งหมด / สร้างกิจกรรมใหม่
  PATCH, DELETE   /api/events/[id]
                     แก้ไข / ลบกิจกรรม


  ------------------------------------------------------------------
  [ TASKS & SUBTASKS — สิ่งที่ต้องทำ ]  (6)
  ------------------------------------------------------------------
  GET, POST       /api/tasks
                     ดึงงานทั้งหมด / สร้างงานใหม่
  PATCH, DELETE   /api/tasks/[id]
                     แก้ไข / ลบงาน
  POST            /api/tasks/[id]/subtasks
                     เพิ่มรายการย่อย (subtask) ในงาน
  PATCH           /api/tasks/[id]/subtasks/reorder
                     จัดลำดับ subtask ใหม่ (ตอนลากสลับตำแหน่ง)
  POST            /api/tasks/[id]/breakdown
                     *AI* แตกงานใหญ่เป็น subtask อัตโนมัติ
  PATCH, DELETE   /api/subtasks/[id]
                     แก้ไข / ลบ subtask


  ------------------------------------------------------------------
  [ AI — ผู้ช่วยอัจฉริยะ ]  (3)
  ------------------------------------------------------------------
  POST            /api/chat
                     แชทกับเอ็ดดี้ + แปลงข้อความเป็น event/task
  POST            /api/ai/analyze-event
                     วิเคราะห์ความหนาแน่น/เวลาชนกัน ตอนสร้างกิจกรรม
  POST            /api/ai/weekly-summary
                     สรุปภาพรวมตารางของสัปดาห์


  ------------------------------------------------------------------
  [ PROFILE — โปรไฟล์ ]  (1)
  ------------------------------------------------------------------
  PATCH           /api/profile
                     แก้ไขโปรไฟล์ (ชื่อ / bio-นิสัย / อวาตาร์ /
                     เวลาที่สะดวก / timezone)


  ------------------------------------------------------------------
  [ GOOGLE CALENDAR ]  (1)
  ------------------------------------------------------------------
  GET             /api/google/calendar
                     ดึงกิจกรรมจากปฏิทิน Google ของผู้ใช้
                     (อ่านอย่างเดียว มาแสดงร่วมในปฏิทิน Eddy)


  ------------------------------------------------------------------
  [ GROUPS — ระบบกลุ่ม ]  (12)
  ------------------------------------------------------------------
  GET, POST       /api/groups
                     ดึงกลุ่มที่ฉันอยู่ / สร้างกลุ่มใหม่
  GET,PATCH,DELETE /api/groups/[id]
                     รายละเอียดกลุ่ม / แก้ไข / ลบกลุ่ม
  GET             /api/groups/invitations
                     คำเชิญเข้ากลุ่มที่รอฉันตอบรับ
  POST            /api/groups/[id]/invite
                     เชิญสมาชิกเข้ากลุ่มด้วยอีเมล
  POST            /api/groups/[id]/respond
                     รับ / ปฏิเสธคำเชิญเข้ากลุ่ม
  DELETE          /api/groups/[id]/members/[memberId]
                     ออกจากกลุ่ม (ตัวเอง) / เจ้าของเอาสมาชิกออก
  PATCH           /api/groups/[id]/me
                     ตั้งค่าความเป็นส่วนตัวของฉันในกลุ่ม
                     (ให้เพื่อนเห็นชื่อกิจกรรม หรือแค่ "ไม่ว่าง")
  GET             /api/groups/[id]/calendar
                     ปฏิทินกลุ่ม — ตารางของสมาชิกทุกคนซ้อนกัน
  GET, POST       /api/groups/[id]/tasks
                     ดึงงานกลุ่ม / เพิ่มงานกลุ่ม
  DELETE          /api/groups/[id]/tasks/[taskId]
                     ลบงานกลุ่ม
  POST            /api/groups/[id]/distribute
                     *AI* หาเวลาว่างร่วม + กระจายงานให้สมาชิก
  POST            /api/groups/[id]/assignments/[assignmentId]/respond
                     ยืนยัน/ปฏิเสธงานที่ได้รับ -> ลงปฏิทินส่วนตัว


========================================================================
 3) สรุป
========================================================================

  API ภายใน 29 endpoint แบ่งเป็น 8 กลุ่ม:
     Auth(2) · Categories(2) · Events(2) · Tasks(6) · AI(3) ·
     Profile(1) · Google Calendar(1) · Groups(12)

  External API 4 ตัว:
     Gemini · Google OAuth · Google Calendar · Neon (PostgreSQL)

  เทคโนโลยี: Next.js API Routes + Prisma (ORM) + PostgreSQL
             ทุก endpoint ที่ต้องล็อกอิน มีการตรวจสอบสิทธิ์เสมอ
